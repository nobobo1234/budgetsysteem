# Beveiliging

Een kwetsbaarheid gevonden? Meld hem privé via GitHub: [**Report a vulnerability**](https://github.com/nobobo1234/budgetsysteem/security/advisories/new) (tab **Security**). Open er geen publiek issue of PR voor.

Vermeld wat je vond, hoe het te reproduceren is en welke versie (commit) je gebruikte. Dit is een hobbyproject van één persoon: er is geen vaste reactietermijn, maar meldingen worden serieus genomen.

Maak een kwetsbaarheid pas openbaar als er een fix is, of uiterlijk 90 dagen na je melding (coordinated disclosure). Na een fix volgt een GitHub security advisory.

Alleen de laatste versie op `main` krijgt fixes. Wie zelf host, werkt bij met `git pull` en opnieuw bouwen (zie [docs/SELFHOST.md](docs/SELFHOST.md)).

Het beveiligingsontwerp (sessies, passkeys, upload-tokens, headers) staat in [docs/SPEC.md](docs/SPEC.md).

## English

Please report vulnerabilities privately via [GitHub private vulnerability reporting](https://github.com/nobobo1234/budgetsysteem/security/advisories/new), not in a public issue. We follow coordinated disclosure: please wait for a fix, or at most 90 days after your report, before disclosing publicly. Only the latest commit on `main` is supported.
